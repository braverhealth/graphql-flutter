# Star Wars Demo

### Client side

This example no longer includes the legacy local server package.
Run it against a compatible GraphQL backend exposed at `http://127.0.0.1:3000/graphql`
and `ws://127.0.0.1:3000/subscriptions`.

- `flutter run` to run it on the ios device
- `flutter run -d chrome` for web support:
